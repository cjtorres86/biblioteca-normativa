# Biblioteca normativa · Licencias médicas

Sitio estático con las normas del proyecto de automatización de licencias médicas
(Informe 00.1 · Subdepartamento GDP-SLEP · Dirección de Educación Pública).

- `index.html`: la página. Lista las 100 normas por grupo, con búsqueda, filtros y botones de descarga.
- `docs/`: los textos oficiales en PDF, en una carpeta por grupo.

Para actualizar una norma, reemplaza su PDF en `docs/` manteniendo el mismo nombre.
Para agregar una norma nueva, hay que agregarla también en los datos de `index.html`.

Corte normativo: 8 de octubre de 2026. No reemplaza la revisión del área jurídica de la DEP.
